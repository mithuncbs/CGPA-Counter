# CGPA Counter

A simple **C program** to calculate **SGPA** and **CGPA** semester-wise for students.  
Supports **up to 8 semesters** and **6 courses per semester**.  

## Features
- Input semester data (course name, credit, marks)
- Calculate SGPA for each semester
- Calculate overall CGPA
- Save and load data from a text file
- View all semester details in a clean table
- Text-based menu with color highlighting

## Usage
1. Compile the program with `gcc cgpa_counter.c -o cgpa.exe`
2. Run the program: `./cgpa.exe` or double-click `cgpa.exe` on Windows
3. Use the menu to input, view, save, or load data
